# HCICG - Weeks 01-03 Image Processing Lab
This repository contains the image processing lab for Weeks 01-03.

## Project Structure
HCICG/
├── images/
│   └── original.jpg
├── outputs/
│   ├── pixel_views.png
│   ├── adjustments.png
│   └── blur_and_edges.png
├── weeks01-03_image_lab.py
├── requirements.txt
└── README.md

## Setup
git clone <your-repo-url>
cd HCICG
pip install -r requirements.txt

## How to Run
python3 weeks01-03_image_lab.py
# Windows:
python weeks01-03_image_lab.py

## Input / Output
Input: images/original.jpeg
Output:
- outputs/pixel_views.png
- outputs/adjustments.png
- outputs/blur_and_edges.png
